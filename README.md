# Cognifyz Software Development Internship

This repository contains the Python projects completed as part of my Cognifyz Software Development Internship.

# Tasks Completed

# Task 1 – Python Quiz Game

A Python quiz application that allows users to select a difficulty level and answer Python-related multiple-choice questions. The application validates user input and displays the final score.

# Task 2 – Number Patterns

A Python program that generates different number patterns based on the number of rows entered by the user.

# Task 3 – CRUD Application

A Python-based task management application implementing CRUD operations:

* Create tasks
* View tasks
* Update tasks
* Delete tasks

The application uses Object-Oriented Programming with a Task class and includes input validation.

# Task 4 – Temperature Converter

A Python program that converts temperatures between Celsius and Fahrenheit. It validates the entered temperature and conversion unit.

# Task 5 – Persistent CRUD Application

An enhanced task management application that implements CRUD operations with persistent data storage.

Tasks are stored in a JSON file, allowing the data to remain available when the application is closed and reopened.

# Task 6 – Web Scraping

A Python web-scraping application that uses Requests and BeautifulSoup to retrieve and process information from a user-provided website URL.

The application extracts:

* Page title
* Headings
* Quotes
* Authors

# Technologies Used

* Python
* Object-Oriented Programming
* CRUD Operations
* JSON
* File Handling
* Requests
* BeautifulSoup
* Web Scraping

# How to Run

First, clone or download this repository.

Then open a terminal in the main project folder:

cd Cognifyz_Software_Development

Each task is located inside its own folder. Navigate into the required task folder before running its Python file.

# Task 1

cd Task_1_Number_Guessing_Game
python quiz_game.py

# Task 2

cd Task_2_Number_Patterns
python number_patterns.py

# Task 3

cd Task_3_CRUD_Application
python task_manager.py

# Task 4

cd Task_4_Temperature_Converter
python temperature_converter.py

# Task 5

cd Task_5_Persistent_CRUD
python task_manager.py

For Task 5, the tasks.json file is created automatically when tasks are saved.

# Task 6

Task 6 requires the requests and BeautifulSoup libraries.

Install them using:

pip install requests beautifulsoup4

Then:

cd Task_6_Web_Scraping
python web_scraper.py

Follow the instructions displayed by each application.
